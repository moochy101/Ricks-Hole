# Rick face assets

This repository does **not** bundle copyrighted character artwork. The display expects 75×75 PNG files named:

`HAPPY.png`, `LOOK_L.png`, `LOOK_R.png`, `BORED.png`, `SMART.png`, `EXCITED.png`, `INTENSE.png`, `ANGRY.png`, `SLEEP.png`, `BROKEN.png`.

If you already have the working installation on your Pi, run:

```bash
./scripts/copy-assets-from-live-install.sh
```

Review the rights/licence for any artwork before publishing it in a public GitHub repository.
